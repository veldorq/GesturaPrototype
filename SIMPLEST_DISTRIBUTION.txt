=====================================
TROUBLESHOOTING (For You/Customers):
=====================================

PROBLEM: Build failed during BUILD_ONE_CLICK.bat
SOLUTION:
  → Ensure Python 3.10+ is installed
  → Run: pip install -r requirements.txt
  → Check antivirus isn't blocking PyInstaller
  → Ensure 2GB free disk space

PROBLEM: .exe file is too large (>300MB)
SOLUTION:
  → Normal! Includes Python + libraries
  → Can't reduce size without breaking standalone feature
  → If needed, use UPX compression (already enabled)

PROBLEM: Antivirus flags .exe as suspicious
SOLUTION:
  → False positive (PyInstaller apps often flagged)
  → Submit to antivirus vendor for whitelisting
  → Use code signing certificate (costs $$$)
  → Document this in customer FAQ

PROBLEM: Customer reports "Camera not found"
SOLUTION (tell customer):
  • Check camera is plugged in
  • Close Zoom/Skype/Teams
  • Windows Settings → Privacy → Camera
  • Enable "Let desktop apps access camera"

PROBLEM: Customer reports .exe won't run
SOLUTION (tell customer):
  • Right-click → Run as Administrator
  • Re-extract from ZIP (don't run inside ZIP!)
  • Check Windows version (needs 10 or 11)
  • Disable antivirus temporarily

PROBLEM: Gestures not responsive
SOLUTION (tell customer):
  • Improve lighting
  • Move hand closer (1-2 feet)
  • Make clearer hand shapes
  • Hold gesture for 1-2 seconds
