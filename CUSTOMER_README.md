# 🎮 Hand Gesture Control - Customer Guide

## What This Is
Control your web browser using **hand gestures** through your webcam! No keyboard, no mouse - just wave your hand.

---

## ⚡ Quick Start (3 Steps)

### 1️⃣ Download & Extract
- Download the ZIP file
- Right-click → **Extract All**
- Open the extracted folder

### 2️⃣ Run the Application
- Double-click **`HandGestureControl.exe`**
- Click **"Allow"** for camera permission
- A camera window will open showing your hand

### 3️⃣ Start Using Gestures!
- Position your hand in front of the camera
- Open your palm → **Scrolls down**
- Close your fist → **Scrolls up**
- Point index finger → **Moves cursor**

**That's it!** No installation, no setup.

## 💡 Tips for Success

### Best Lighting
- ✅ Bright room or natural light
- ❌ Dark rooms make detection harder

### Best Distance
- **1-2 feet** from camera
- Too close = hand fills screen
- Too far = hand too small

### Best Technique
- Make **clear, distinct** gestures
- **Hold** gesture for 1 second
- Use **one hand** at a time
- Practice for 2 minutes to get comfortable

## 🔧 Troubleshooting

### "Camera not found" Error
**Solution:**
1. Check camera is plugged in (USB cameras)
2. Close other apps using camera (Zoom, Skype, Teams)
3. Go to **Windows Settings** → **Privacy** → **Camera**
4. Enable "Let desktop apps access your camera"

### Gestures Not Working
**Try this:**
- Improve lighting
- Move hand **closer** to camera
- Make **clearer** hand shapes
- **Hold** gesture longer (1-2 seconds)

### Application Won't Start
**Try this:**
1. Right-click .exe → **Run as Administrator**
2. Check antivirus isn't blocking it
3. Re-extract from ZIP file
4. Make sure you have **Windows 10 or 11**

### Too Sensitive / Not Responsive
- Adjust distance from camera
- Try different lighting
- Practice making clearer gestures

## ❓ Frequently Asked Questions

**Q: Do I need to install Python?**  
A: **No!** Everything is bundled in the .exe file.

**Q: Does this work on Mac or Linux?**  
A: Currently **Windows only**. Mac/Linux support coming soon.

**Q: Can I use two hands?**  
A: The system tracks **one hand** at a time for simplicity.

**Q: Is my camera feed recorded?**  
A: **No!** Everything stays on your computer. No recording, no upload.

**Q: How do I uninstall?**  
A: Just **delete the folder**. No installation = no uninstall needed!

**Q: Why is the .exe file large (~200MB)?**  
A: It includes Python interpreter + all libraries so you don't need to install anything.
