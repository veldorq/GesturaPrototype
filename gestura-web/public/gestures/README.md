# Gesture GIFs

This folder contains GIF animations for each gesture displayed on the "How It Works" page.

## Required GIF Files

Place the following GIF files in this directory:

1. **pinch-zoom.gif** - Animation showing pinch zoom gesture
2. **swipe.gif** - Animation showing swipe navigation gesture
3. **open-palm.gif** - Animation showing open palm scroll gesture
4. **fist.gif** - Animation showing closed fist (pause media) gesture
5. **call-sign.gif** - Animation showing shaka/call sign (mute toggle) gesture
6. **thumbs-down.gif** - Animation showing thumbs down (close window) gesture

## Specifications

- **Format**: GIF
- **Recommended Size**: 400x400 pixels or similar square aspect ratio
- **File Size**: Keep under 500KB for optimal loading
- **Background**: Transparent or dark background to match the site theme
- **Loop**: All GIFs should loop continuously

## Fallback

If a GIF fails to load or is missing, the interface will automatically fall back to displaying the emoji icon for that gesture.
